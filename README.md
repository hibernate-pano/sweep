# Clear Browsing Data

一个只做一件事的 Chrome 扩展：**点一下，清掉你刚留下的痕迹。**

不用翻三层设置，不用勾二十个复选框。打开面板，按一下按钮，走人。

---

## 装到浏览器里

1. 打开 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录
4. 工具栏上会出现图标（建议固定到工具栏）

快捷键：`⌘⇧K` / `Ctrl+Shift+K` 直接唤出面板。

---

## 设计

面板的主体是一个**环形足迹计**：圆环按 LocalStorage / IndexedDB / 离线缓存的条目数分成三段，
一色三阶（钴蓝 → 中蓝 → 浅蓝）。

范围切到「全部网站」或「自选」时，圆环不会消失，而是换成**整个浏览器的足迹构成**：
历史多少条、Cookie 多少条、涉及多少个网站。这里有个诚实的限制——
扩展没有读取「整个浏览器缓存占多少字节」的接口，所以那三段只数真正数得出来的东西，
不编一个假的体积数字。历史条数跟着时间范围走；没勾选的清理项会压暗并标一个「未清理」，
免得把圆环当成「这次会清掉什么」的清单。

按下按钮后，圆环切换成**进度盘**：中心走百分比，弧按比例涨，主按钮里同时有一道填充在推进；
图例换成这次要清的几项，一项一项打勾。真正做完之前最多报 99%——
最后一步还在跑的时候，进度条不会骗你说已经清完了。

真实清理往往只有一百多毫秒，快到动画还没展开就没了。所以这个圈有一个**最短时长**：
数据该瞬间删完瞬间删完，但进度圈至少走完这一圈——不然用户根本不知道发生了什么。

配色是**冷纸 + 墨 + 一枚钴蓝信号**：墨色只给主按钮（浅色下近黑、深色下信号蓝），
信号色只给数据与选中态。没有装饰性渐变，结构靠细分割线，不靠卡片套卡片。

跟随系统深浅色，两套配色都单独调过对比度。

**单一原则**：不管勾了哪些项，永远是同一个按钮、同一套范围、同一句承诺。
主按钮只清浏览器本地的数据——账号里的东西不会因为你按了它就没了。

## 它到底清什么

面板上有四个开关，默认的组合是「日常够用、不痛」：

| 项目 | 包含 | 默认 |
|---|---|---|
| **缓存** | 磁盘缓存、Cache Storage | ✅ |
| **站点数据** | LocalStorage、IndexedDB、Service Worker（本地会话、偏好设置） | ✅ |
| **Cookie** | Cookie、表单自动填充 | ⬜ 会登出 |
| **历史记录** | 浏览历史 | ✅ |

三个范围，**默认是「全部网站」**：

- **全部网站** — 整个浏览器。这是默认项。清之前会二次确认：浏览历史删了就是删了。
  圆盘显示整个浏览器的足迹：历史多少条、Cookie 多少条、涉及多少个网站。
- **当前网站** — 只清你正看着的这个站。面板会先告诉你这个站留下了多少东西。
- **自选** — 一份你自己维护的站点名单。设置页会列出最近 7 天去过的站，点一下就能加进名单。

时间范围只对历史记录和缓存生效，可以选「全部 / 1 小时 / 24 小时 / 7 天」。
它是一个**绝对时间点**（`Date.now() - 范围`），所以选「24 小时」就真的只动最近一天，
不会顺手把更早的数据一起清掉。

## 保留登录状态

设置页里可以维护一份「保留登录」名单。名单里的网站**不会被登出**：

- **Cookie 和本地存储保留** —— 登录态、偏好设置都在这里，不动。
- **缓存和历史记录照清** —— 它们跟登录没关系，没理由跟着一起留下。

面板上，名单内站点的「站点数据」和「Cookie」会标一个**保留**，清理后这两项显示「已跳过」，
其余照常清除。

一个诚实的限制：**名单按主域名生效。** 填 `mail.google.com` 会保留整个 `google.com`，
因为浏览器的 Cookie 删除接口无法按子域名单独操作。这一点在设置页里也写明了。

---

## 云端会话：只在你明确要求时才删

有些站（比如 ChatGPT、Claude）把对话存在**服务器**上，跟着你的账号走。
清浏览器数据不会删掉它——本地那份没了，账号里的还在。

面板在检测到这些站时，会多出一张卡片，写明账号里还剩多少条会话，
并给一个**独立的「删除」按钮**。这个按钮调用的是网站自己的接口，用的是你当前的登录态，
一条一条删，删之前必须二次确认——因为不可逆。

> 主按钮**不会**碰云端会话。想删账号里的东西，只能去点卡片上那个按钮。
> 「全部网站」范围同样不会碰它：清浏览器数据不该顺手删掉你账号里的东西。

## 自动清理

三种触发方式，都在设置页里：

- **浏览器启动时** — 开浏览器就跑一次
- **退出浏览器时** — 关掉最后一个窗口时触发；如果来不及执行，下次启动会补做
- **每天定时** — 到点跑一次

自动清理按设置页里的默认范围执行。范围是「当前网站」时会直接跳过——
后台没有「当前标签页」这个概念，把它静默降级成「全部网站」等于在用户不知情时清空整个浏览器。
设置页会写清楚当前默认范围触发自动清理会发生什么。

---

## 隐私

- 不联网，不上传任何东西。所有设置和清理记录都在 `chrome.storage.local` 里。
- 云端会话删除用的是你浏览器里已有的登录态，扩展本身不接触任何凭据。
- 权限都是功能必需的：`browsingData`、`history`、`cookies`、`storage`、`tabs`、
  `scripting`（探测并删除页面里的本地数据）、`alarms`、`favicon`。

## 开发

纯原生 JS + ES Module，没有构建步骤，改完代码在扩展页点一下刷新即可。

```
manifest.json
src/
  popup.html / popup.css / popup.js    面板
  background.js                        Service Worker：定时、启动/退出触发
  lib/
    constants.js                       清理项、范围、默认设置
    util.js                            格式化、域名解析
    settings.js                        设置与清理记录的读写
    cleaner.js                         核心清理逻辑
    footprint.js                       整浏览器的足迹统计（历史 / Cookie / 站点数）
    chat.js                            聊天站点注册表
    pageScripts.js                     注入到页面执行的函数
options/
  options.html / options.css / options.js
icons/                                 由 tools/make-icons.py 生成
tools/
  make-icons.py                        图标生成
  preview-server.py                    本地预览（带 chrome.* 假实现）
  preview/chrome-mock.js
```

### 本地预览

扩展页面依赖 `chrome.*` API，不能直接双击打开。用预览服务器：

```bash
python3 tools/preview-server.py
# http://127.0.0.1:8765/src/popup.html
# http://127.0.0.1:8765/options/options.html
```

它会注入 `tools/preview/chrome-mock.js`，提供一份带假数据的 `chrome.*` 实现。

### 加一个新的聊天平台

在 `src/lib/chat.js` 的 `CHAT_SITES` 里加一条，然后在 `src/lib/pageScripts.js` 写一个
自包含的注入函数（**不能引用模块作用域的任何东西**，否则注入后报 ReferenceError）：

```js
{
  id: 'kimi',
  label: 'Kimi',
  hosts: ['kimi.moonshot.cn'],
  fn: kimiPage,   // 接收 'list' | 'delete'
}
```

函数只做两件事：列出会话、逐条删除。不要用任何批量删除接口。

## 已知限制

- 云端会话删除依赖网站内部接口，接口变了就会失效。失效时面板会明确显示「删除失败」，
  而不是假装删掉了 0 条。
- 一次最多处理 100 条云端会话（单页上限）。会话特别多时需要点多次。
- `chrome.browsingData` 的 `origins` 参数对 `history` 不生效，所以单站点历史是逐条删的，
  站点历史特别多时会慢一点。
- 保留登录名单按主域名生效，没法只保一个子域。
- 「全部网站」范围的圆盘只统计历史条数、Cookie 条数和网站数，
  缓存和站点数据占多少字节扩展拿不到，所以不显示。
