## 详细说明

```
清理浏览足迹，本来该是三下点击的事。

Sweep 把它压成一下。

打开面板，四个开关（缓存 / 站点数据 / Cookie / 历史记录），一个按钮。按完走人。

▍看得见的足迹

面板顶上是一个环形足迹计，直接告诉你这个浏览器里积了多少东西：
历史多少条、Cookie 多少条、涉及多少个网站。没勾选的清理项会压暗并标一个「未清理」，
免得把圆环误读成「这次会清掉什么」。

▍范围由你定

· 全部网站 —— 整个浏览器（默认）
· 当前网站 —— 只清你正看着的那个站，面板会先告诉你它留下了多少
· 自选 —— 一份你自己维护的站点名单，设置页里点一下最近去过的站就能加进去

还可以在设置页限定时间范围（全部 / 1 小时 / 24 小时 / 7 天），对所有清理项都生效。

▍清理时看得见进度

按下按钮，圆环切成进度盘：中心走百分比，弧按比例涨，主按钮里同时有一道填充在推进，
图例一项一项打勾。真正做完之前最多报 99%——最后一步还在跑的时候，
进度条不会骗你说已经清完。

▍不想被登出

清理站点数据或 Cookie 会让你退出那些网站的登录——很多站把登录令牌存在 LocalStorage 里，
只清 Cookie 并不代表你还登录着。Sweep 把这件事写在脸上，并且在设置页提供一份「保留登录」名单：
名单里的网站，Cookie 和本地数据都留着，缓存和历史照清。

▍自动清理

可以在设置页打开「浏览器启动时」「退出浏览器时」「每天定时」三种触发方式。
默认范围是「当前网站」时自动清理会直接跳过——后台没有「当前标签页」的概念，
悄悄降级成清空整个浏览器是不能接受的行为。

▍不联网

没有服务器，没有账号，没有遥测。Sweep 不发起任何网络请求，也不包含任何远程代码。
设置和清理记录只存在你自己的浏览器里。

快捷键：⌘⇧K / Ctrl+Shift+K

免费、开源。
```

## 隐私实践问卷

### 单一用途声明

> 按下按钮时，清除浏览器本地保存的浏览数据——缓存、站点数据、Cookie、历史记录。

### 数据使用

| 问题 | 回答 |
|---|---|
| 是否收集或使用用户数据？ | **否**。扩展只在本地读取浏览历史 / Cookie / 当前页存储用于**统计与删除**，读取结果仅显示在面板上，不上传、不共享、不用于任何其它目的。 |
| 是否与第三方共享用户数据？ | **否** |
| 是否传输用户数据？ | **否**。扩展不发起任何网络请求，包内无远程代码。 |
| 数据是否在传输过程中加密？ | 不适用（不传输）。 |
| 用户能否请求数据删除？ | 不适用（不收集）。数据只在本机 `chrome.storage.local`，卸载扩展即清除。 |
| 是否使用远程代码？ | **否** |
| 是否出售或转让用户数据？ | **否** |

### 权限理由（逐条）

| 权限 | 理由 |
|---|---|
| `browsingData` | 扩展的核心功能：删除浏览数据。 |
| `history` | 统计历史条数与涉及网站数；「当前网站 / 自选」范围下按来源删除历史（`browsingData` 的 origins 不作用于 history，只能逐条删）。 |
| `cookies` | 统计 Cookie 条数，供圆环显示。不读取 Cookie 的值。 |
| `storage` | 保存用户设置与清理记录，仅存本机。 |
| `scripting` | 在**用户当前打开的那个页面**中读取 localStorage / IndexedDB / Cache Storage 的条目数与占用字节，用于「当前网站」范围的圆环统计。不会注入任何修改页面的代码。 |
| `alarms` | 用户开启「每天定时自动清理」后到点触发。 |
| `favicon` | 在面板里显示当前站点的网站图标。 |
| 站点访问权限 `http://*/*`、`https://*/*` | 上述按站点生效的能力都需要站点访问权限。扩展只在打开面板或执行清理时访问，且只触及上表列出的数据。 |

## 审核备注（给审核员）

```
感谢审阅。

Sweep 是一个单用途扩展：按一下按钮，清除浏览器本地的浏览数据。

【怎么测】
1. 装上后点工具栏图标（或按 ⌘⇧K / Ctrl+Shift+K）打开面板。
2. 面板顶部是环形足迹计，显示当前范围内的历史条数、Cookie 条数、涉及网站数。
   切换「全部网站 / 当前网站 / 自选」可以看不同范围。
3. 四个开关默认勾选「缓存 / 站点数据 / 历史记录」，Cookie 默认不勾
   （Cookie 会让你退出登录）。
4. 点「清空全部网站」，圆环会走一段百分比进度，图例逐项打勾。
   完成后可在设置页看到清理记录。
5. 想验证数据确实被删：清理后打开 chrome://settings/content/all 或
   chrome://history 对照即可。

【关于几个可能被问到的地方】
· 没有任何远程代码，也不会下载执行任何东西。扩展包内全部是静态文件。
· 扩展不发起任何网络请求。可以在开发者工具的 Network 面板里确认：
  打开面板、清一次数据，全程零请求。
· 没有账号、没有服务器、没有遥测。
· 站点访问权限是为了两件事：统计 Cookie / 历史条数，以及在当前页面里
  读取本地存储的条目数（画那个圆环）。注入的函数只做只读的统计，
  不修改页面、不读取页面内容、不读取表单输入。
· 面板上会明确写出「这次会不会让你退出登录」，因为站点数据同样会导致登出。
· 「保留登录」名单里的网站，Cookie 与本地数据都会被保留。

【关于破坏性操作】
主按钮一次点击即永久删除所选范围的浏览数据，扩展刻意不做二次确认
（它存在的意义就是「一下就清掉」）。范围、时间范围、保留登录名单
都在面板和设置页里可以精确控制，商店描述与隐私政策里也写明了删哪些东西。

隐私政策：https://hibernate-pano.github.io/sweep/
源码：https://github.com/hibernate-pano/sweep
```
