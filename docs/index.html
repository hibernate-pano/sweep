Sweep

隐私政策

最后更新：2026-11-26 ｜ 适用版本：1.0.0

Sweep 是一个只在你点击时才动手的 Chrome 扩展。它的全部工作都在你的浏览器本地完成。 不收集、不上传、不共享任何个人信息，也不发起任何网络请求。

扩展没有服务器、没有账号、没有遥测。你装的这个扩展不会把你的浏览历史、Cookie 或任何东西发到任何地方。

它会碰哪些数据

Sweep 只在你按下「清空」按钮（或你打开的自动清理触发）之后才会删除浏览器本地的数据。 为了让你在按下按钮之前知道将要发生什么，它会先读取并统计下面几项：

数据读来做什么读的范围
浏览历史数出有多少条、涉及多少个网站全部网站，或你选定的范围
Cookie数出有多少条全部网站，或你选定的范围
当前页面的 localStorage / IndexedDB / Cache Storage数出这个站留下了多少条本地数据、占了多少字节只有你正在看的那个站，且只在你打开面板时

读到的这些数字只用来画面板上的圆环和那几行文字。它们不会离开你的设备。

被删除的数据分四类，由你在面板上勾选：

  • 缓存 — 磁盘缓存、Cache Storage 离线缓存包
  • 站点数据 — LocalStorage、IndexedDB、Service Worker、文件系统
  • Cookie — Cookie，以及自动填充保存的表单数据
  • 历史记录 — 浏览历史

哪些东西它不会碰

  • 书签
  • 保存的密码（密码管理器里的）
  • 下载记录
  • 其它扩展的数据（清理时显式排除了扩展来源）
  • 你账号里的东西 —— 服务器上的聊天记录、订单、云端文件一概不动。 扩展只清浏览器本地这一份副本；你登录的网站服务器上留着什么，它管不着也碰不到。
  • 自动填充的表单数据，除非你选的是「全部网站」范围（它不按站点存放，只能整体清）

保存的东西

Sweep 在你的浏览器本地（chrome.storage.local）保存三样东西：

  • 你的设置（范围、勾了哪几项、时间范围、主题）
  • 「保留登录」名单
  • 最近 30 条清理记录（时间、范围、清了多少条）

这些只存在你的机器上。清除浏览器数据或卸载扩展会一并清掉它们。

网络

Sweep 不发起任何网络请求。扩展包内没有任何远程代码， 也不会从网上下载并执行任何东西——你装的就是你运行的全部。

权限与理由

权限为什么需要
browsingData删除浏览数据这件事本身
history统计历史条数、按来源删除历史
cookies统计 Cookie 条数
storage保存你的设置（只存在本机）
scripting在你正在看的那个页面里读取本地存储的条目数和占用，用来画那个圆环
alarms你开启「每天定时」后到点触发
favicon显示当前站点的网站图标
http://*/*、https://*/*上面几项要按站点生效，就必须有站点访问权限。扩展只在需要时访问，且只读上面列出的那几项

自动清理

你可以在设置页打开三种触发方式：浏览器启动时、退出浏览器时、每天定时。 它们按你在设置页选的默认范围执行同样的删除操作，同样不联网、不上传。 默认范围是「当前网站」时，自动清理会直接跳过——后台没有「当前标签页」的概念， 悄悄降级成「清空整个浏览器」是不能接受的行为。

儿童

Sweep 不收集任何人的个人信息，因此也不区分成年人和儿童。

变更

这份政策会跟着扩展的版本一起更新。如果某个版本改变了数据处理方式， 这里会写清楚，并且商店页上的变更说明会同时更新。
